Noto Sans Regular and Bold are bundled for local PDF generation. No remote font service is contacted at export time.
Source: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
License: SIL Open Font License 1.1, included in OFL.txt.
These font files support Latin, Greek, and Cyrillic text. PDF export checks character coverage and reports unsupported characters rather than silently dropping them. DOCX can use fonts installed on the reader's system.
